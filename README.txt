# V NISANTH — Cinematic Portfolio

## Files
- index.html
- style.css
- script.js
- assets/images/*

## Run
No build system is required. Open `index.html` in a browser.

Anime.js is loaded from CDN in `index.html`.

## Add your real photo
Place your photo at:
`assets/images/hero-photo.jpg`

The hero automatically replaces the placeholder when that file exists.

## Important editable placeholders
- `ADD_HIG_AI_AUTOMATIONS_QUOTE_HERE`
- `ADD_GITHUB_LINK_HERE`
- `assets/images/hero-photo.jpg`

No unsupported achievements, testimonials, percentages, or repository URLs were invented.
